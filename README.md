# Gestión de Préstamo de Herramientas Comunitarias

Aplicación web desarrollada para gestionar el préstamo de herramientas comunitarias en la ciudad de Córdoba. El sistema busca facilitar el acceso a herramientas para trabajadores de oficio, emprendedores y aficionados, promoviendo una gestión organizada, transparente y accesible.

## Propósito del sistema

Actualmente, muchas personas no pueden acceder a herramientas debido a su alto costo o a su uso ocasional. Además, los préstamos informales suelen generar pérdidas, demoras y falta de control.

Este proyecto busca resolver estas problemáticas mediante una plataforma digital que permita administrar préstamos de herramientas, mantener un registro organizado y generar información útil para mejorar la toma de decisiones.

##  Funcionalidades principales

El sistema incluye las siguientes funcionalidades:

- Registro y administración de herramientas.
- Gestión de usuarios del sistema.
- Control de préstamos y devoluciones.
- Visualización del estado de disponibilidad de herramientas.
- Alertas sobre vencimientos de préstamos.
- Organización del inventario comunitario.
- Seguimiento y trazabilidad del uso de herramientas.

##  Instalación y ejecución (Maqueta)

Actualmente el proyecto se encuentra en etapa de maqueta/prototipo.

### Pasos para ejecutar la maqueta:

1. Descargar o clonar el repositorio:

```bash
git clone https://github.com/ByteBuildersCba/Inventory-App-FullStack.git
```

2. Acceder a la carpeta del proyecto:

```bash
cd Inventory-App-FullStack
```

3. Abrir la carpeta **maqueta**.

4. Ejecutar el archivo principal (`index.html`) desde el navegador.
